Build a full-stack web application called **AI1Net** — a dashboard-based platform (NOT a landing page).

The app is a unified AI hub where users can access multiple AI models, manage usage, and interact with a token-based ecosystem ($AI1NET).

---

## 🧱 CORE REQUIREMENTS

### Tech Stack

* Next.js 14+ (App Router)
* TypeScript
* Tailwind CSS
* ShadCN UI (modified to neo-brutalism)
* Zustand (state management)
* Prisma + PostgreSQL (or SQLite for dev)
* NextAuth (authentication)
* API routes for backend logic

---

## 🎨 DESIGN SYSTEM — NEO BRUTALISM

Style must follow:

* Thick borders (`border-3 border-black`)
* Hard shadows (`shadow-[4px_4px_0px_black]`)
* Flat colors (no gradients)
* High contrast (black, white, yellow, blue, red)
* Sharp edges (no rounded-lg everywhere, minimal rounding)
* Bold typography (uppercase headings)

UI Feel:

* Retro + Web3 + Hacker aesthetic
* Inspired by brutalist dashboards, not SaaS minimalism

---
